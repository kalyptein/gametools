Resources
* A a resource is an item
* It can be used or taxed.
	* use: gently exploit the resource at a sustainable level
	* tax: heavier use of the resource.
		* Add 1 tick, then roll d6.  If less than the number of ticks, the resource is depleted and the ticks cleared (thus you can always tax a resource once without risking depletion).
* If can be full, depleted, or consumed.
	* full: the resource is plentiful
	* depleted: the resource is running low.
		* It often provides different, lesser results when used or taxed.
		* If a depleted resource is depleted again, it is consumed.
	* consumed: the resource is used up and gone
* It can be refreshed or renewed.
	* Refresh: remove all tax ticks.
	* Renew: restored from depleted or normal.
